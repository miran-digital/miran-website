# تحویل نهایی Miran Shop

این سند همراه نسخه منتشرشده نهایی می‌شود و وضعیت واقعی را از ادعای تکمیل جدا می‌کند.

## تکمیل‌شده در این انتشار

- ورود و ثبت‌نام مستقل مشتری با Supabase Auth، تأیید ایمیل، خروج امن و بازیابی کامل رمز.
- نشست مشتری با Cookie امن و HttpOnly؛ ورود مدیریت همچنان جدا و مبتنی بر حساب مالک ChatGPT است.
- گزارش فروش و سلامت عملیات در پنل بر اساس داده واقعی D1 و خروجی CSV.
- Rate Limit پایدار برای سفارش، پرداخت، نشانی، دیدگاه، فروشنده، فیش و آپلود.
- اصلاح Permissions Policy برای لوکیشن اختیاری همان Origin.
- Content Security Policy و تکمیل Headerهای امنیتی Worker.
- حذف Metadata موقت پیش‌نمایش از Production.
- هماهنگ‌سازی درباره ما، تماس، راهنمای خرید، حریم خصوصی، شرایط و کوکی‌ها با وضعیت واقعی.
- Migration افزایشی جدول Rate Limit، بدون حذف یا تغییر داده‌های تجارت.
- مستند معماری، QA، پشتیبان و بازگشت.

## هفت مورد تعویقی با تصمیم مالک

1. واردکردن شماره کارت واقعی در مدیریت.
2. دریافت و تنظیم Merchant ID زرین‌پال.
3. آزمایش یک خرید واقعی کنترل‌شده.
4. تکمیل تصویر واقعی ۲۰ محصول از ۲۱ محصول.
5. تعیین تکلیف فروشنده قدیمی ناقص؛ پیشنهاد عمومی او مسدود می‌ماند.
6. تکمیل سیاست/اتصال ارسال، مرجوعی و Backup زمان‌بندی‌شده با Restore Test.
7. فعال‌سازی SEO Index پس از آماده‌سازی نهایی؛ `SITE_INDEXABLE` فعلاً غیرفعال است.

## محدودیت صداقت گزارش

- پرداخت زرین‌پال بدون Merchant ID واقعی کامل یا فعال نیست.
- کارت‌به‌کارت بدون شماره کارت واقعی فعال نیست.
- Core Web Vitals در این محیط اندازه‌گیری نشده است.
- Backup تحویلی، Logical D1 است و باینری R2 را شامل نمی‌شود.
- تأیید حقوقی نهایی سیاست ارسال/مرجوعی و هویت حقوقی کسب‌وکار بر عهده مالک است.

## نسخه و انتشار

نسخهٔ این تحویل نرم‌افزار: **۲۹**

- Commit دقیق منبع در تاریخچهٔ همان نسخه در Sites ثبت می‌شود.
- نشانی اصلی: `https://almiran.ir`
- TypeScript، Lint و Build: موفق
- تست‌ها: ۶۶ از ۶۶ موفق
- محصولات: ۲۱؛ سفارش‌ها: ۲؛ فروشندگان: ۱؛ تنظیمات فروشگاه: ۱

فایل تحویل شامل منبع برنامه، Migrationهای کامل D1، Schema، راهنمای بازیابی و
مستندات QA است. Secretها و شناسه‌های پرداخت واقعی عمداً در فایل تحویل قرار ندارند.
برای جلوگیری از افشای نشانی و اطلاعات مشتری، دادهٔ زندهٔ D1 داخل بستهٔ منبع قرار
نگرفته است؛ خروجی زنده فقط از مسیر مالک `مدیریت ← پشتیبان` دریافت می‌شود.

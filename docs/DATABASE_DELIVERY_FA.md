# تحویل پایگاه‌داده Miran Shop

## اجزای داخل بسته

- تعریف کامل جدول‌ها و ارتباط‌ها در `db/schema.ts`
- همهٔ Migrationهای افزایشی در `drizzle/`
- Repositoryهای خواندن، نوشتن، گزارش و پشتیبان در `db/`
- راهنمای بازگردانی در `docs/RESTORE_GUIDE_FA.md`

## وضعیت پایگاه‌داده زنده هنگام تحویل نسخه ۲۵

پایگاه‌داده دارای ۱۷ جدول عملیاتی بود. کنترل زنده شامل ۲۱ محصول، ۲ سفارش،
۳ ردیف سفارش، ۱ نشانی مشتری، ۱ پرونده فروشنده و ۱ تنظیمات فروشگاه بود.

## چرا دادهٔ زنده داخل ZIP نیست

دادهٔ زنده می‌تواند نشانی مشتری، شناسه حساب و تاریخچه مدیریتی داشته باشد. قراردادن
آن کنار کد منبع، یک نسخهٔ اضافی و ناامن از اطلاعات شخصی می‌سازد. مالک می‌تواند در
لحظهٔ انتقال، از پنل مدیریت خروجی منطقی D1 بگیرد. این خروجی باید رمزگذاری و جدا از
کد منبع نگهداری شود. فایل‌های رسانه‌ای R2 نیز باید جداگانه منتقل و کنترل شوند.

Secretهای میزبانی، Merchant ID زرین‌پال و اطلاعات کارت هیچ‌وقت نباید داخل ZIP،
Git یا فایل پشتیبان پایگاه‌داده قرار گیرند.

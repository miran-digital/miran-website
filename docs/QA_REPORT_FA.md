# گزارش QA نسخه کاندید انتشار

## کنترل‌های خودکار

- TypeScript Typecheck
- ESLint با قواعد React، Hooks و دسترس‌پذیری
- Build کامل Vinext/Cloudflare Worker
- اعتبارسنجی Artifact و `default.fetch`
- ۶۳ تست Unit/Integration/Rendered Worker
- Migration افزایشی `0011_lucky_vapor.sql`

## پوشش تست

- تقویم شمسی/میلادی و ساعت ایران
- تخفیف درصدی و ثابت ریال/تومان
- پیام‌های هم‌زمان هدر
- حساب، مالکیت نشانی و API ناشناس
- Snapshot نشانی Checkout
- Idempotency سفارش و پرداخت
- رزرو موجودی و Rollback خطا
- زرین‌پال غیرفعال بدون Merchant ID
- کارت‌به‌کارت، فیش و بررسی مدیریت
- مدارک فروشنده و Gate تأیید
- پشتیبانی، اعلان و دیدگاه خرید تأییدشده
- Backup منطقی همه جدول‌ها
- Rate Limit پایدار بدون نگه‌داری شناسه خام
- گزارش عملیاتی بدون PII
- CSP و Security Headerها
- SEO Routes و عدم افشای صفحات خصوصی در Sitemap

## کنترل پیش‌نمایش

صفحه اصلی در پیش‌نمایش واقعی دسکتاپ با `dir=rtl`، هدر، جست‌وجو، ورود، انتخاب
نشانی و لینک‌های محصول باز شد؛ عرض محتوا از Viewport بیشتر نبود. خطای Console مربوط
به کد سایت مشاهده نشد؛ تنها پیام Extension مرورگر آزمایشی ثبت شد.

مرورگر ابری هنگام ورود مستقیم به API سلامت ادامه نشست را بر اساس سیاست داخلی مسدود
کرد. بنابراین Core Web Vitals و یک Pass تصویری مستقل موبایل در این محیط اندازه‌گیری
نشده و نباید به‌عنوان نتیجه اندازه‌گیری‌شده گزارش شود. Responsive CSS، Build و
Rendered Tests موفق‌اند، اما این‌ها جای تست دستگاه واقعی را نمی‌گیرند.

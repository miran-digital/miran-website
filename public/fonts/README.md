# MIRAN web fonts

- Vazirmatn: local variable WOFF2, weights 100–900, loaded from the project source through `next/font/local`.
- Estedad: local SemiBold 600 WOFF2, used only for important headings.

Neither font requires a Google Fonts request or a previous build cache.

Both typefaces are distributed under the SIL Open Font License 1.1. The license text is stored in `SIL-OFL-1.1.txt`.

Official sources:

- https://github.com/rastikerdar/vazirmatn
- https://github.com/aminabedi68/Estedad
